# 老项目上下文索引初始化指南（按需读取）

> **读取边界**：**仅当用户显式要求“初始化本项目上下文索引”时读取执行；常规起草、修订、定稿任务严禁读取本文件。**

## 执行步骤

1. **继承项目红线**：先读取目标仓库根目录的项目规范文件（`AGENTS.md` / `CLAUDE.md` / `GEMINI.md`），完整继承禁读目录、只读基线保护等全部红线。
2. **生成初版架构地图（≤ 250 行；优先遵循项目规范文件已声明路径，默认 `docs/CODEBASE_MAP.md`）**：
   - 参照同目录 [context-templates.md](./context-templates.md) 的 4 个通用工程槽位（模块职责表、外部入口清单、公共复用设施与测试夹具、依赖方向与禁改边界）；
   - 按分阶段只读方式扫描目录拓扑与核心入口，严禁通读 lockfile、构建产物或大二进制快照。
3. **生成初版上下文台账（≤ 100 行；优先遵循项目规范文件已声明路径，默认 `docs/HANDOFF_LEDGER.md`）**：
   - 参照同目录 [context-templates.md](./context-templates.md) 的 3 个滚动分区（未清零遗留待办、已实测环境与依赖陷阱、近期关键契约变更最近 5–8 项）；
   - 遍历既有 `docs/handoffs/*.md` 时，**仅定向定位读取「遗留待办 / 已知限制 / 环境陷阱 / 复审闭环」相关章节**，严禁通读历史执行单全文。
4. **零破坏红线**：
   - **严禁移动、重命名或删除任何历史执行单**（不自动建 `archive/` 目录，避免误移在途单或破坏文档间相对链接；若用户需要归档可自行手工整理）；
   - 若目标路径已存在 `CODEBASE_MAP.md` 或 `HANDOFF_LEDGER.md`，仅做增量补充与去重，严禁覆盖丢失已有手工记录。
5. **汇报与收口**：
   - 向用户汇报新建/更新的文件路径与精简摘要，交用户审阅确认；
   - **严禁自动 `git commit` 或 `git push`**。
