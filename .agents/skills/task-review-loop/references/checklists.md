# Independent Review Attack-Surface Checklists

本清单作为 `task-review-loop` 审查员的按需参考手册：先逐项核查通用的 6 类工程攻击面，再按当前项目技术栈挑选对应的扩展项核查。

---

## 一、通用 6 类攻击面细化核查

### 1. 跨模块接线与复用一致性
- 新增的公共函数、服务方法、配置项、CLI 子命令或路由是否真正接入了所有生产入口？
- 同类入口（如 CLI / HTTP API / RPC / UI / 定时任务 / 批处理脚本）是否存在一处改了、另一处漏改的情况？
- 是否放着已有工具函数不用而复制粘贴出“第二套实现”，导致后续口径分叉？
- 修改公共签名或返回值后，全仓库调用方（含测试与脚本）是否全部同步？

### 2. 第三方依赖与并发/资源生命周期陷阱
- 对不熟悉的第三方库 API、版本行为、默认值或弃用警告，是否通过只读实测或读源码确认，而非凭猜测？
- 并发/异步路径：有无在异步事件循环中直接做同步阻塞 IO/CPU 重操作？共享可变状态有无竞态？
- 资源生命周期：数据库连接、文件句柄、HTTP 会话、锁、缓存、临时文件/目录在正常与异常路径下是否都会正确关闭/释放？
- 权限与暴露面：是否无意放宽了路径白名单、CORS、权限校验、敏感字段脱敏或默认绑定地址？

### 3. 异常路径与边界输入
- 常见边界值：空字符串、全空白、空集合、`null`/`None`/`undefined`、0/负数/极大值、`NaN`/`Infinity`、非法编码、重复键、超长输入。
- 失败与半成功状态：当多步操作（写库 + 写文件 + 调外部服务）中途抛错时，状态是否完整回滚或保持幂等？
- 禁止静默失败：是否存在宽泛 `catch`/`except` 吞掉异常、返回误导性默认值、或在缺失前置资源时静默建空库/空表掩盖故障？

### 4. 测试真实性与断言强度
- 杜绝弱断言：只断言结果非空、长度 > 0、退出码为 0 或未抛异常，却没校验关键输出内容、透传给下游的参数、状态变化或落盘结果。
- 杜绝过度 Mock：Mock 范围过大导致被测核心逻辑根本没跑，或测试替身与真实接口签名漂移。
- 覆盖完整性：正例、关键边界、异常反例（断言精确错误类型/错误码）以及既有行为的兼容回归是否齐备？
- 确定性：测试是否依赖当前时间、随机种子、网络、本地绝对路径或执行顺序？

### 5. 实测数字与文档口径真实性
- 汇报与文档中的测试数、覆盖率、耗时、数据统计是否与最后一次真实运行日志逐字一致？
- 验证方式表述是否诚实区分“端到端实机操作”与“脚本/单测/Mock 模拟”？
- 最后一轮改完代码后，受影响的验证步骤、联调或生成产物是否基于**最终代码**重跑？
- 执行单、README、API 文档、注释中是否残留已废弃的旧设计或旧选项描述？

### 6. 只读保护与仓库干净度
- 项目约定的历史只读产物、基准快照、哈希锁文件是否完好无损？
- `git status` 是否干净无多余未跟踪文件（临时日志、沙箱空目录、调试截图、`.bak`）？
- 源码中是否残留 `print`/`console.log`/`debugger` 等调试语句？
- 任务追踪文件（如 `tasks.md`）与 Git 状态是否符合收口策略（未提前勾选/提交）？

## 二、按技术栈可选扩展检查项

### Python 项目
- 可变默认参数（`def f(x=[])`）、闭包延迟绑定、意外修改入参对象。
- 区分 `None` 与假值（`0`/`""`/`[]`/`False`）；浮点校验 `math.isnan`/`math.isinf`。
- 既有测试中的 `monkeypatch` / `unittest.mock.patch` 目标路径是否因重构 import 路径而失效。
- `sqlite3` / 文件上下文管理器退出时是否关闭连接（注意 `with sqlite3.connect(...)` 只提交事务，不自动 `close()`）。
- 依赖与环境隔离（如离线模式、虚拟环境、特定 warning 是否零新增）。

### TypeScript / JavaScript / 前端项目
- `any` / `as unknown as` 类型逃逸是否掩盖真实空值或协议不匹配。
- React/Vue 等副作用清理（`useEffect` cleanup、取消过期请求防竞态、事件监听解绑）。
- `undefined` vs `null` vs `0` vs `""` 的判空与可选链行为；`JSON.parse` 与外部输入运行时校验。
- SSR/CSR 水合一致性、环境变量泄露到客户端打包产物（`NEXT_PUBLIC_*` / `VITE_*`）。

### Go / Rust / 后端服务
- Go：`context.Context` 透传与取消、goroutine 泄漏、`defer` 关资源及 error 忽略（`_ = ...`）、slice 共享底层数组并发改写。
- Rust：生产路径滥用 `unwrap()`/`expect()`、锁跨 `.await` 持有导致死锁、`Drop` 与取消安全（cancel safety）。
- 通用后端：幂等键、超时与重试上限、分页边界、数据库事务隔离与索引/N+1 查询、错误码不泄露内部堆栈。

### 数据 / ML / 评测与只读产物项目
- 数据泄漏（训练/验证/评测集串用）、随机种子未固定导致不可复现。
- 只读原始数据目录与历史评测产物是否保持只读、校验和一致。
- 评测指标口径（样本数、过滤条件、失败样本计分方式）是否与历史基线可比，未悄悄剔除失败样本。
