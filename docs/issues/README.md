## 新建记录模板（`NNN-short-slug.md`）

后续遇到类似偶发/待观察问题，按编号递增新建文件并补充到上方索引表，建议沿用以下结构：

```markdown
# Issue NNN：<一句话描述现象>

- **状态**：观察中（暂未复现） / 已复现待修复 / 已修复（附 commit）
- **严重程度**：低 / 中 / 高
- **首次发现**：YYYY-MM-DD（设备型号 / iOS 版本）
- **关联任务**：`<spec-dir>` / `<Task IDs>` / [执行单](../handoffs/xxx.md)
- **相关源码锚点**：`path/to/file.swift:L1-L20`

## 1. 现象描述与现场线索
- 用户观察到的具体行为、触发条件、持续时长、周期与截图/数值证据。

## 2. 排查过程与已排除项
- 按时间线记录已经做过的验证、核查过的文件、确认无关的模块，避免以后重复排查。

## 3. 当前核心假设
- 列出剩余尚未被推翻的候选根因与对应的判别特征。

## 4. 复现与取证指南（零改代码优先）
- 写清下次复现时如何用内置调试面板 / 录制工具 / 日志采集决定性证据。

## 5. 后续处置记录
- 日期 + 新线索 / 最终根因 / 修复 commit。
```
